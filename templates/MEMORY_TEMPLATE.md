# 제목

## Context

어떤 작업/상황에서 발생했는지 2~5문장 이내로 작성합니다.

## Symptom

겉으로 드러난 오류/현상을 짧게 작성합니다.

## Root Cause

확인된 실제 원인을 작성합니다. 추측이면 저장하지 않거나 confidence를 낮춥니다.

## Wrong Approach

## Correct Approach

다음에 같은 유형을 만났을 때 재사용할 수 있는 해결 순서를 작성합니다.

## Reusable Rule

한두 문장으로 압축한 핵심 교훈을 작성합니다.

## Verification

테스트, 빌드 성공, 재현 제거, 문서 확인 등 무엇으로 검증했는지 작성합니다.
